# Matrix3D
3D Matrix wallpaper based on HTML

Animated Matrix 3D wallpaper for your desktop. This is a simple HTML file. The animation is purely symbols and math—no video, animated images, or anything like that. This wallpaper was created at my son's request after watching the legendary 1999 film The Matrix.

The pseudo-volume is achieved by varying font sizes, creating the impression that individual character columns are in the background, while others appear to be in the foreground. By opening the file in any text editor, you can change many parameters, including the characters themselves, their drop speed, fade speed, the number of simultaneous lines on screen (their density), the "PC-Neo" communication lines, and much more.

To set this wallpaper on your desktop, you can use the Lively Wallpaper app. I've provided instructions below.

1. Install Lively. Open the Microsoft Store and search for Lively Wallpaper, or download the installer from the project's official GitHub repository. Follow the Windows prompts during installation. Lively works with web pages, including HTML splash screens (https://github.com/rocksdanister/lively).
2. Save the file. Make sure the file is named index.html and is located in a separate folder, such as "Documents\GabikMatrix."
3. Add it to Lively. Open the app and drag index.html into the Lively window. If dragging and dropping doesn't work, click the Add Wallpaper button or +, select the file from the browser, and confirm the addition. Then click the wallpaper that appears to set it as your desktop wallpaper. Dragging and dropping HTML files into the app is supported (https://github.com/rocksdanister/lively).
4. Configure the app. In Lively's settings, enable "Start with Windows." If your computer lags while playing games or running full-screen apps, enable automatic screensaver pause for these situations. On a laptop, you can also pause the screensaver when running on battery power. Lively supports pause rules for full-screen apps and battery power (https://github.com/rocksdanister/lively).

If the HTML splash screen doesn't launch, make sure index.html opens in the browser. Web wallpapers may also require the Microsoft Edge WebView2 component to be installed.
